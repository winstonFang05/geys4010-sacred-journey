# 尋聖之旅網站方向

2026-11-03 · 首版設計記錄

## 要解決的問題

當村校、老店、村落和民間文化空間改變或消失，使用者即使找到地名和年代，也難以知道這個地方對街坊有甚麼意義。網站把可追溯的資料和有公開許可的社區回憶並排整理。項目名稱保留「尋聖」，範圍涵蓋日常文化與社區歷史。

主要讀者是香港的年輕人、新來港人士，以及對地方歷史有興趣的公眾。居民和場地管理者同時是知識提供者，也是決定如何呈現故事、是否公開位置及是否適合到訪的人。

## 訪客路徑

1. **找地方。** 從地圖點選地區，或以地名、主題搜尋檔案。列表是同等入口，方便手機與鍵盤使用者。
2. **讀故事。** 以一件物品、一個生活場景或一段記憶切入。短摘要之後交代資料性質、來源和待核事項。
3. **留線索。** 首版提供離線模板。若開放收件，按線索、待核實、已取得公開同意和發布分開管理，投稿與公開授權分開處理。
4. **從現場回到故事。** 待獲場地同意後，QR 碼連到固定的故事網址。交通、開放及無障礙資訊需要有核實日期，導賞資訊待活動確認後再上架。

## 內容與發布

- 每篇正式故事需有固定 ID、雙語標題與摘要、概略地區、資料類型、來源、待核問題及最近審核日期。收錄判斷和公開位置精度分開記錄。
- 採訪內容、照片和精確位置按各自授權處理。公開資料可作為研究入口，重製相片須另核權利。需要保留在組內的內容存於團隊另設的工作區。
- 首輪組內驗收請以三個任務檢查，從地圖找故事、在手機辨識來源與待核細節、切換語言後使用同一篇故事連結。後續正式試用可配合提案記錄故事數、使用情況、意識變化及社區回饋。
